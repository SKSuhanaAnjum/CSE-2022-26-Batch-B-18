Project Overview

Water pollution is a critical concern affecting ecosystems and water quality. This system provides an integrated approach to assess river quality using automated detection of pollutants and objects present in water.

Using YOLOv10 object detection algorithm, our system identifies various pollution types including acid pollution, dead animals, eutrophication, fish oil, and plastic pollution, along with objects like bottles, cardboard, glass, metal, leaves, paper, and water containers.
